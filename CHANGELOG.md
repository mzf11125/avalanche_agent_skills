## [0.1.0] - 2026-05-03

### Added
- `avalanche-concepts` skill: architecture overview, Etna/ACP-77 changes, Ethereum comparison, 80+ term glossary, FAQ
- `avalanche-icm` skill: Teleporter quick-start, architecture, sending/receiving, relayer setup, debugging, 5+ examples
- `avalanche-evm` skill: Subnet-EVM precompiles, Hardhat/Foundry config, genesis, 8+ examples
- `avalanche-ictt` skill: TokenHome/TokenRemote deployment, ERC-20 & native bridging, 5+ examples
- `avalanche-network` skill: AvalancheGo config, validator setup, Docker Compose stack, Prometheus/Grafana monitoring
- React + Vite showcase site with landing page and interactive MCP tool playground
- GitHub Actions markdown lint workflow
- `skillsrc.json` skill registry
